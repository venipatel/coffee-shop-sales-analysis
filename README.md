# coffee-shop-sales-analysis
## Project overview
Data analysis project using Excel  to analyse sales trends, customer behaviour, peak hours, staff availability.

## Tools Used
- Micosoft Excel
- Pivot Tables
- Pivot Charts
- Data Cleaning
- Data Visualisation

## Key Insights
- Sales performance by day of the week
- Transactions by Hours
- Peak business hours
- Prouct Category Performance
- Store location comparision

## Business Objective
Use transaction data to identify patterns can help to improve sales performance, staffing desicions and business operations
